=== rules ===
Write:
- objective_text: one plain sentence that states the end state the activity was meant to reach, as a fact about the objects. It is a statement, never a command or an instruction: it never starts with a verb that tells someone what to do. Use state words, never motion words.
- has_end_state: true when the activity is meant to leave at least one object in a particular state or place; false when it leaves no object end state, as in a dance, waving or a gesture. When has_end_state is false, objective_text says in one plain sentence what the activity is, still as a statement and never as a command, and there is no object_end_state item.
- primary_target: {target_rule}; primary_destination: {destination_rule}.
- requirements: the end-of-clip conditions. When has_end_state is true, every task-relevant object gets one end-state item (kind object_end_state). When a robot or a humanoid does the activity, it gets exactly these items (kind robot_end_state): holding, one of gripper_open or gripper_closed (for its gripper or hand), and one position item (withdrawn, at_home_pose or near_object). When a person does the activity, give no robot_end_state item. Every item has a value or status unsure; never leave a mandatory item out.

For each requirement:
- predicate from: inside, on_top_of, touching, in_gripper, lifted, at_location, unchanged, activated, state, holding, gripper_open, gripper_closed, withdrawn, at_home_pose, near_object, tool_lifted, other;
- object and ref_object are {ref_rule}, or "none" (for holding, ref_object is the held object or "none"; holding nothing is predicate holding, ref_object none, value false);
- value is "true" or "false" (or the state word for predicate state);
- status: required (the task description states it, or it must hold for the stated outcome to hold), incidental (seen but neither stated nor necessary), or unsure;
- unsure_kind: "perception" when the images cannot show the fact, "intent" when the fact is visible but the task description does not settle whether it is required, "none" otherwise;
- basis: task_string, physical_necessity or observed;
- achieved: whether this clip reached it: true, false or unknown;
- deciding_frame and deciding_camera: where the fact is best judged; visibility: for each camera, visible, partial or not_visible at that frame; reason: a short reason.

Nothing that happened only during a failed attempt is a requirement.
