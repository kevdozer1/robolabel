=== input ===
These images are {n_images} frames of one video clip from camera {camera}, evenly spaced from the first frame to the last. The line before each image gives its frame number, its time and the camera. The clip may show a robot, a humanoid or a person.

=== task ===
The dataset's task description is: "{task}".

=== no_task ===
The dataset gives no task description.

=== rules ===
List the objects in the clip that matter for labeling it:
- every object the task description names or implies;
- every object that the robot, the humanoid or the person touches, holds, moves, presses or uses as a tool during the clip;
- every place an object is put into or onto (a box, a basket, a plate, a shelf, a sheet of paper);
- every look-alike: any object of the same kind, or with a similar color or shape, as an object that is handled.
Do not list the robot, the humanoid, the person or parts of their bodies. List at most 10 objects. When no object is named or handled, give an empty list.

For each object give:
- object_id: o1, o2, o3 ... in the order you list them;
- name: a name that picks out this one object in this clip, for example "left black bowl" or "red block near the tray";
- aliases: other short names a person might use;
- category: one of block, container, bowl, plate, bottle, tool, control, cloth, other;
- views: exactly one entry, for camera {camera}. visible is true when the object can be seen in the first image (frame {first_frame}). When visible, x and y are a point on the object in that image and x0, y0, x1, y1 its box, all as fractions of the image width and height (0 is left or top, 1 is right or bottom). When the object cannot be seen in the first image (it is hidden there, or it appears later), set visible to false and all six numbers to 0.
